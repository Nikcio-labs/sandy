Direction & tokens

Type gets a personality: Gabarito for display and row names — rounded and warm for a non-technical audience — with the system sans for UI text and mono strictly for commands and YAML.

Every state a sandbox can be in

States come from the CLI, so the UI only ever reports what it was told. Pending actions (start/stop/restart) spin in the pill without inventing a state of their own. Empty states host the dune — the app's own face — instead of a generic glyph.

Try: run both steps — the CLI install streams output while the step spins, the sign-in hands off to the browser and returns signed in, and the dialog hands off to the app with a fade. Skippable any time; Sandy works until it truly needs the missing piece. The dialog also supports reduced motion by dropping straight to the next state.

Motion lab

Isolated interactions, each following the framework: enter with ease-out under 300ms, nothing animates from scale(0), press feedback everywhere, and destructive actions made deliberate.

Buttons answer

Press scales to 0.97. Confirmation morphs in place with a blur crossfade instead of a jarring label swap.

Dialogs arrive, don't pop

Modals stay center-anchored but enter from scale(0.95) with a fading backdrop — never from nothing.

Connect to sandbox

Toasts stack and leave politely

Enter and exit share one direction (bottom), transitions — not keyframes — so rapid-fire actions never restart mid-flight.

Tabs morph color as one surface

A clipped duplicate list slides the white pill between tabs — one continuous move instead of three colors racing each other.

Tooltips warm up, then keep pace

First tooltip waits 500ms to avoid accidents; siblings after it appear instantly — the toolbar feels faster.
